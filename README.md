# Mi portafolio

Portafolio web hecho con HTML, CSS y JavaScript para Skillnest.

## Cómo publicarlo en GitHub Pages
1. Sube todos los archivos a un repositorio nuevo (solo para el portafolio).
2. Ve a Settings > Pages.
3. En "Branch" elige `main` y la carpeta `/ (root)`. Guarda.
4. Tu sitio quedará en `https://tu-usuario.github.io/nombre-del-repo/`.
